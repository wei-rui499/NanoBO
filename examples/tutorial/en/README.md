# English practice files

All values are SYNTHETIC. These exercises are mathematical teaching examples, not wet-lab measurements or recommended chemistry recipes.

Open the project in one numbered folder. For a fixed refill exercise, open pending-practice.chembo.json and import followup-results.csv: 6 completed / 2 pending becomes 8 completed / 0 pending.

The full lookup tables are simulated answer keys. Do not import the whole answer key when practising one batch. Class labels must match the language of the project: Aggregated / Spheres / Rods, or Success / Failure.

See the Chinese or English screenshot walkthrough in docs/STEP_BY_STEP.*.md. The sibling original practice folders retain Chinese labels and the same numerical values.
