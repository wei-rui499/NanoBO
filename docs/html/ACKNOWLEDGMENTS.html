Acknowledgments / 公开致谢

SynthBO 是一个面向化学研究者的独立桌面实验规划界面。我们感谢下列科研软件、算法论文及其原作者和维护者；SynthBO 的界面和安装包不改变这些成果的学术归属。

特别感谢 Florian Häse、Loïc M. Roch、Matteo Aldeghi、Riley J. Hickman、Alán Aspuru-Guzik 及其合作者为 Phoenics、Gryffin、Chimera、Atlas 与 Olympus 作出的贡献。感谢 BoTorch、GPyTorch、PyTorch 与 scikit-learn 的作者和维护者提供现代优化与概率建模基础；感谢 Willi Gottstein / BO-MCP 项目提供保留在本软件中的兼容后端。完整作者列表见 REFERENCES.bib。

SynthBO 自身的贡献

SynthBO 提供独立的桌面交互、严格表格输入、可执行配方域、实验回填与项目保存、引擎进程集成、实际模型诊断、结果可视化、模拟功能验收和安装包构建。科学优化方法、论文及原始软件的作者署名按各自来源保留。

SynthBO 不是上述作者、课题组、机构或项目的官方桌面产品，以上致谢不表示他们参与、审核或背书 SynthBO。引用论文与履行开源许可证是两件分别需要处理的事；致谢页不能替代许可证、版权声明、对应源码或修改记录。

发表使用本软件的研究时，请按如何引用引用实际使用的模型，不只引用 SynthBO。
