固定版本与修改

固定上游提交及实际兼容性修改见 docs/UPSTREAM_MODIFICATIONS.md 和相应 upstream/*/UPSTREAM_REVISION。已修改的上游文件应继续保留原版权，并带有显著修改标记。不得将这些兼容性修改描述为重新发明上游算法。

  • Gryffin：由原始 .pyx 重建 C 扩展，保留来源和修改标记。
  • Atlas：采集优化器适配及已知约束的原单位解码修正。
  • Olympus：源码快照版本与元数据加载兼容修正。
  • BO-MCP：保留固定 bo-engine 兼容后端。新版 SynthBO 增强工作流直接调用 BoTorch／scikit-learn，不将其归为 BO-MCP 全产品或原创算法。

二进制再分发

公开发行文件应使用同一版本的应用源码、依赖版本和源码档案。新平台或依赖升级后应重新生成清单。参考文献和致谢分别见 REFERENCES.bib、ACKNOWLEDGMENTS.md；它们不能代替本节所需的法律材料。
