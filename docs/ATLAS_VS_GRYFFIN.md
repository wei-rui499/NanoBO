# Atlas 与 Gryffin：给实验化学家的比较

核查日期：2026-10-31。

Atlas 是面向实验科学的贝叶斯优化框架：读入已经完成的实验，拟合响应模型，再平衡“寻找高性能条件”和“探索不确定区域”，推荐下一批实验。它不是预测所有化学体系的预训练大模型，也不包含可直接套用到任何纳米颗粒体系的生长规律。

| 问题 | Gryffin | Atlas |
| --- | --- | --- |
| 核心路线 | 基于 Phoenics 思路的贝叶斯核密度／核回归，扩展到类别和混合参数 | 以高斯过程为核心，使用 BoTorch、GPyTorch |
| 特别突出的设计 | 利用物理化学描述符组织类别选择；static/dynamic 方式利用或细化描述符 | 在统一框架里处理多类实验优化任务 |
| 连续、整数、类别与混合参数 | 支持 | 支持 |
| 批量推荐 | 支持 | 支持 |
| 多目标、已知／未知可行性约束 | Gryffin 当前源码已有相关支持，多目标使用 Chimera；不是 Atlas 才有 | 提供相应模块及不同优化策略 |
| 多保真、借用历史任务、误差稳健性 | 相关生态另有 Gemini、Golem 等工具，不能把这些都算成基础 Gryffin 自动具备的能力 | 官方框架明确列出多保真、元学习、输入／测量噪声及搜索空间调整等能力 |

来源：[Gryffin 官方说明](https://github.com/the-matter-lab/gryffin)、[Atlas 官方说明](https://github.com/the-matter-lab/atlas)、[Atlas 官方文档](https://matter-atlas.readthedocs.io/en/latest/)。具体模块仍应按实际数据和使用条件核对。

Atlas 的扩展能力可以用几种实验需求理解：

- **多保真**：将较便宜的模拟或简化测量与昂贵的正式实验结合，而不是把不同精度数据直接混成等价结果。
- **元学习／历史任务信息**：利用相关任务的已有数据；前提是任务间存在可利用的关系，并非任意旧数据都有帮助。
- **稳健优化**：关注加液、温控等输入误差下仍表现良好的条件；需要提供误差模型，不能从普通结果表自动推断真实操作误差。

对于“Alán 团队目前最好的是不是 Atlas”，可支持的判断是：**Atlas 是团队较新、功能较全面的通用实验 BO 框架之一，值得作为 NanoBO 的主力候选；没有依据称其为所有实验问题上的最好模型。**功能更丰富、发表更晚和实际优化更有效，是三个不同问题。

相关研究生态在 2026 年还有 [BO-MCP](https://github.com/AccelerationConsortium/bo-mcp) 等工程。BO-MCP 将 BoTorch/BayBE 后端、MCP/REST 和实验记录编排结合；它不是已经被证明全面击败 Atlas 的单一新模型，BayBE 也不应归称为该课题组原创算法。[相关工具核查](../research/related_tools.md)保留了来源关系与角色区别。

对连续配方加类别选择的化学问题，合理做法是用相同的变量空间、历史实验和评价预算比较 Gryffin 与 Atlas；再看新条件的实际效果、重复实验波动及模型计算成本。在完成这种比较前，不能仅凭名称或年代判定哪一种更适合具体材料体系。

**NanoBO 当前接入范围**：Gryffin 支持单目标及 Chimera 层级多目标；Atlas 提供单目标推荐。增强 BoTorch 工作流支持单目标、Pareto、分类、步长、候选表和联合配方约束。描述符输入、多保真、元学习尚未开放；上游完整能力不等于当前界面已经全部实现。
